Frozen daily snapshots

Each snapshot is frozen at the last write of that day and is never rewritten, so that what Kaikei knew on a given date can be checked.

How to cite

Kaikei, “Where the flow is”, https://kaikei-media.github.io/, accessed 2026-09-02. Data: https://kaikei-media.github.io/data/kaikei.csv

Please cite the primary source alongside it: Kaikei collects and dates figures rather than asserting them, so both are needed to check anything.

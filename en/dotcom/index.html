ドットコムのとき、合図はいつ出たか

問い: 解経がT3に並べている「流れが変わる合図」は、出たときにはもう暴落が終わっている種類のものではないか。

答え: 半分はそうだった。 そして解経の現在の8つの合図は、遅行するものに偏っている。

3. ここから言えること

(a) 遅行する合図が「出ていない」ことは、安心の材料にならない。

①③④は、ドットコムでは暴落が始まってから1〜2年後に出た。

解経のいまの読みは「Cに入る破断の合図はまだゼロ」だが、

ドットコムでも天井の日に①③④はゼロだった。

(b) 「capexが増えている」は、天井が来ていない証拠にならない。

通信設備投資が天井を打ったのは 株価の天井から9か月後。

指数が−62%になっても、設備投資はまだ前年を上回っていた。

解経はいま「4社ともcapex増額」をC入りしていない根拠として挙げているが、

この読み方はドットコムでは外れた。

(c) 天井は1つの日付ではない。

Lucent 1999-12 → Nasdaq 2000-03 → Nortel 2000-07 → 設備投資 2000-Q4。

売り手の株が先に天井を打ち、支出は後から天井を打った。

「まだ皆が使っている」は、いちばん最後に崩れる。

(d) 先に出た合図は、事件ではなく比率だった。

Lucent で最初に壊れたのは四半期決算に載っている比率だった。

売上+6〜33%に対し、売掛金+41〜64%・在庫+45〜74%が8四半期続いた。

DSOはF1999の89日からF2000の102日へ。

これは発表を待つ必要がなく、決算が出るたびに誰でも計算できた。

「出た／出ていない」の事件ではなく、閾値つきの連続値として見るべきものだった。

(e) 解経の⑥の但し書きは、たぶん逆。

いまの記録は⑥について「Bの深化を示すものでCの発火ではない」と書いている。

ドットコムでは、⑥にあたるものがいちばん早い警告だった。

この類推が効かないところ

類推は道具であって答えではない。効かない場所を先に書いておく。

0. 額で比べない（前の版の誤り）

インフレも資産の種類も違うので、契約残高の絶対額を並べても意味がない。

GDP比で取る。

ドットコムの通信投資のピークGDP比 1.2%
AI関連（DC・ハード・ネットワーク）2026年Q1の実測GDP比 1.4%（2015-22年平均は0.7%）
ハイパースケーラのcapex 2027年見込みGDP比 3.1%

すでに当時のピークを超えている。見込みでは約2.6倍。

額を並べるより、この比のほうが強い。

1. 普及の摩擦が無い

2000年8月の米国世帯: PC保有 51.0%、インターネット接続 41.5%、ブロードバンド 4.4%（NTIA）。

ファイバは、まずPCを買ってもらうところから始まる需要のために敷かれた。

いまAIを使うのに要る端末は、すでに全員が持っている。この差は大きく、実在する。

ただし裏がある。 1999年は最後の1マイルの費用を消費者が払った（PC・モデム・加入料）。

いまは計算の費用が全部作り手の帳簿に載り、使う側は月0〜20ドル。

普及の摩擦は、費用を作り手に移すことで消した。

上限のない利用は、GPUを持つ側にとっては費用の問題になる。

2. 需要が伸び続けることは、資本が守られることを意味しない（最重要）

当時も需要は「上限なし」と信じられていた。標語は 「100日で倍」＝年16倍。

実際のバックボーン通信量の伸びは 1997〜2002年で年約2倍（70〜150%）。

需要は崩壊のあいだもずっと伸び続けた。それでも作り手は潰れた。

理由は、16倍を前提に建てて2倍しか来なかったことと、単価が崩れたこと。

Odlyzko の言い方では、事業計画は「実際の需要を意図的に無視して」作られていた。

→ 問うべきは「需要に上限があるか」ではない。

→ 「調達を正当化した想定と同じ速さで伸びているか」と「いくらで」。

（観測: T3-D1 推論の単価 / T3-D5 AIラボの収益と損失 / T3-D6 SaaSの実利用）

3. 資産の寿命が短い（1と逆向きに効く）

ファイバは約25年。敷いたら残る。だから過剰は10年続いたが、待てば正しくなった（いまは全部点いている）。

GPUは3〜6年。Amazonは2025年1月に一部サーバを6年→5年へ短縮（理由はAIの技術更新の速さ。四半期純利益で約3億ドルの押し下げ）。Metaは5.5年へ延長。

Burryは実際の経済寿命は2〜3年で、2026〜28年に約1,760億ドルの償却不足になると主張している。

25年の資産は需要の遅れを待てる。4年の資産は待てない。

回収は償却期間の中で終わらせる必要があり、現行世代に留まるにはまた使う必要がある。

→ AI capexは、収益の未達に対してファイバより脆い。

4. 帰結 — 速さの見立ては両側に開く

1は「収益が早く立ちうる」側に効き、3は「損が早く出る」側に効く。

ドットコムより遅いのではなく、両方向に速いと見るのが自然。

「ハイパースケーラーがキャッシュリッチだから、下落はゆっくり」については、

当時のキャッシュリッチな巨人もゆっくりだった（Cisco 31か月、Intel 26か月）。

ただし、ゆっくりは浅いを意味しなかった（Cisco 約−90%、Intel 約−80%）。

そしてその緩衝材は解経の記録の中で薄くなっている——

設備投資の借入比率 FY24の9%→32%、Alphabetのcapexが営業CFの115%で上場来初のFCFマイナス。

この調べ方の限界

分母が無い

この文書は壊れた銘柄だけを見て書いている。Lucent、Nortel、JDSU、Cisco、Intel、WorldCom——

全部、崩壊したから記録が残っている企業。

売掛金が売上より速く伸びたが、何事もなく解消した会社は、こちらから見えない。

だから「売掛金の膨張が出たら危ない」と言えても、

「出たうちの何割が崩壊に至るか」は、解経は知らない。

これは調べれば埋まる穴ではない（標本の作り方そのものが歪む）。

埋まらないことを認めて、使い方のほうを変える。

  • 合図を「危ないから売る理由」として使わない。
  • 合図を「次にどこを見るかを決める理由」として使う。
  • 合図が出たのに何も起きない期間を、異常と扱わない。 それが多数派かもしれない。

事例の数が少ない

「先行の合図から天井まで6〜18か月」は Lucent の1例から出ている（n=1）。

Nortel は天井の前に合図が無かったので、この幅の裏づけにならない。

幅の広さは、事例が多いからではなく、事例が1つしかないから。

日付を片側だけ確かめる誤りを、実際にやった

2026-09-01、Lucent の日付だけ確かめ、Nortel は「同じだろう」で書いた。

成り立たない対比を、1つの枠組みの唯一の根拠にしていた。

記録は公開ページ 直したこと に置いた。

2つの事例を並べる前に、両方の日付を確かめる。

ネオクラウドの対応物（CLEC）は、何で落ちたか

Lucent/Nortelで日付を片側しか確かめずに失敗したので、今回は先に確かめた。

Winstar — 与信を出していた側が止めた19日後に破産

Lucentの与信先。何が最初に壊れたかがはっきり記録されている。

日付出来事
1998年Lucentが7億ドル超を貸付。5年の供給契約で追加の融資義務を負う
2001-03-30Lucentが予定していた9,000万ドル超の支払いを実行しなかった。 その後Winstarをデフォルト認定
2001-04-16頃Winstarが約7,500万ドルの利払い不能を公表
2001-04-18Chapter 11申請。 Lucentの供給契約違反が破産の原因だと提訴

最初に壊れたのは需要でもコベナンツでもなく、資金の仕組みそのものだった。

そして与信を止めてから破産まで19日。

いちばん重要な点: Winstarの先行指標は、Winstarの側ではなくLucentの側にあった。

Lucentは2001年度に22億ドルの貸倒引当を積む状態で、自分が苦しくなったから与信を止めた。

Winstarは、金を出していた相手が倒れたから倒れた。

→ いまのNVIDIAは、この「金を出していた相手」の位置にいる。

非市場性有価証券511.6億ドル、5,000億ドルの融資枠組み、SB Energyへの1,050億ドルの保証。

**NVIDIAの貸借対照表は、NVIDIA自身にとっては経路の長い先行指標だが、

ネオクラウドにとっては経路19日の致命的な指標。**

同じ数字が、見る相手によって種別が変わる。

Level 3 — 生き残った側（対照）

倒れた会社ばかり見ると分母が歪むので、生き残った1社も見る。

2000年時点で流動資産 50.45億ドル、営業損失 13.45億ドル/年（1998年の2.05億→1999年7.41億→2000年13.45億と加速）。

長期負債 73.18億ドル。それでも破産していない。

標準的な説明は「早い段階で大量に資金を調達し、手元を厚くしていた」。

参考の比較（精度は粗い。流動資産≠現金、営業損失≠現金流出）

  • Level 3（2000年）: 流動資産 ÷ 年間営業損失 ≒ 3.7年
  • NBIS（2026年）: 現金93億ドル ÷ 四半期のFCF流出34億ドル ≒ 0.7年 ← 誤り。2026-09-01に訂正（消さずに残す）

訂正（2026-09-01・一次資料 Nebius 6-K で確認）

1-3月期の実績は 営業CF +22.58億ドル、設備投資 24.73億ドル、差引フリーCF −2.15億ドル。

設備投資の額をそのままFCFの流出として扱っていた。約16倍の誤り。

同じ割り算をやり直すと 92.98 ÷ 2.15 ≒ 43四半期（約10.8年） になり、結論が逆になる。

さらに、この分母はそもそも使えない。

営業CF(+22.58億ドル)が売上(3.99億ドル)を大きく上回っている。前受けなどが入っているはずで、分解しないと分母にならない。

現金の増加も財務活動+62.96億ドル（転換社債43億ドル・NVIDIAワラント20億ドル）によるもので、厚さは調達の結果。

残るのは Level 3 の側だけ: 「残り月数」が生死を分けた変数だったことは、2000年の側の記録が示している。

いまのネオクラウドについては、まだ測れていない。（記録は T3-F12）
